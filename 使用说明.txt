# 小账本通用版（独立副本）

启动：双击“启动记账.cmd”，打开 http://127.0.0.1:18769/ 。需要 Node.js 24+，无需安装依赖。

原来的“记账程序”目录、18769 端口、Tailscale 和个人账单均保留。本版使用单独的目录、端口、浏览器存储与数据文件，不会自动替换个人版。未复制任何个人账单。

默认英语。在 Settings / 设置里可选择英语、简体中文、西班牙语、法语、日语，立即生效并记住选择。用户填写的账户名与备注保持原样。

初次使用不启用任何币种。在设置里按需添加：美元 USD、欧元 EUR、英镑 GBP、人民币 CNY、令吉 MYR、日元 JPY、韩元 KRW、新加坡元 SGD、澳元 AUD、加元 CAD、港币 HKD、新台币 TWD、瑞士法郎 CHF、泰铢 THB、印尼盾 IDR、印度卢比 INR、越南盾 VND、菲律宾比索 PHP、阿联酋迪拉姆 AED、新西兰元 NZD。

币种独立记账，不进行换算。全部币种金额支持最多两位小数。账户或账单使用中的币种不能移除。语言与启用币种偏好保存在各自设备；同步过来的账单所使用的币种会自动保留。v3 备份包含账户、账单和已启用的币种。

运行 npm test 验证。本版在 GitHub 的 xiaozhangben-public 仓库独立维护，不会替换手机上的个人版。
